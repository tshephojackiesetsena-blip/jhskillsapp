# Design tokens & Storybook

This folder contains the initial design tokens and a Storybook skeleton for the JH Skills CRM UI.

Getting started
1. Install dependencies

   cd frontend
   npm install

2. Run Storybook

   npm run storybook

What this includes
- design/tokens.css — CSS custom properties (the design system tokens)
- design/tokens.json — token JSON for design tools
- frontend/ — Storybook config and a set of initial components + stories
