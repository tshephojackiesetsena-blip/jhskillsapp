# Contributing to JH Skills CRM

Thanks for your interest in contributing. Please follow these guidelines to make collaboration smooth.

- Branching: Create a feature branch from crm-starter or main. Use the naming convention feature/<short-description> or fix/<short-description>.
- Pull Requests: Open PRs against crm-starter for initial work. Include a description, testing steps, and assign reviewers.
- Code Style: Use consistent naming and formatting. For VB.NET follow standard .NET naming conventions. Keep functions small and testable.
- Testing: Add unit tests for new business logic. Include integration tests for DB-related changes when possible.
- Commits: Write concise commit messages; use present tense and reference issues when applicable.
- Issues: Use the provided issue templates to file bugs or feature requests.

If you're unsure, open an issue to discuss the change before starting.
